# AI learning

The owner's personal AI course: a loop of gauge, teach and re-test, built around their real projects.

## Start here
- **Run a lesson:** in Claude Code, type `/tutor-cycle`, or say "next lesson". The skill lives in `.claude/skills/tutor-cycle/`.
- **Rules every session follows:** `CLAUDE.md` in this folder.

## Files
| File | What it is |
|---|---|
| `CLAUDE.md` | Teaching rules: strict teacher, fair questions, one concept per cycle |
| `profile.md` | Who the owner is: setup, projects, how they learn, teaching-style log |
| `knowledge-map.md` | **Source of truth:** the state of all 57 concepts |
| `question-log.md` | Every question asked and answered. Never repeat one. |
| `loop.md` | The approved learning process as UML (Mermaid) |
| `roadmap.md` | The 8 stages, with the current stage and milestones |
| `ai-from-the-ground-up-progress.md` | Scoreboard from the Yo cloud chat (merged into the knowledge map) |
| `2026-10-14-yo-session-transcript.md` | Full transcript of the Yo cloud chat |
| `lessons/` | Lesson pages already built (HTML) |
| `research/` | Deep-research report and notes (October 2026) |
